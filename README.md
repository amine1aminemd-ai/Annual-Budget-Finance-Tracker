# Annual Budget & Finance Tracker

This repository contains a Google Sheets-ready template pack for an annual budget and finance tracker.

## Structure

The files in `templates/` are CSV sheets that can be imported into a Google Sheet. Import each CSV as a separate tab and name the tab exactly as the filename.

## Recommended workflow

1. Create a new Google Sheet.
2. Import each CSV file one by one.
3. Rename each tab to match the CSV name.
4. Keep the `SETTINGS` tab as the control panel.
5. Use `TRANSACTIONS` as the main data entry sheet.
6. Review results in `DASHBOARD`.
